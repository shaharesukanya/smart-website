What is Regular Expression?

A regular expression, commonly called regex, is a pattern used to search, match or validate text. Regex can be useful for extracting emails, numbers, dates, URLs and other text patterns.

Regex Flags

The tester supports common JavaScript regular expression flags including global matching, case-insensitive matching and multiline matching.

Browser-Based Testing

What is a regex tester?

A regex tester lets you enter a regular expression and sample text to see whether the pattern matches the text.

What does the g flag mean?

The global flag tells JavaScript to search for multiple matches instead of stopping after the first match.

What does the i flag mean?

The i flag makes matching case-insensitive. For example, a pattern for "hello" can also match "Hello".

Can regex validate email addresses?

Regex can be used for basic email-pattern checks, although complete email validation can involve additional rules.
