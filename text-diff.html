Frequently Asked Questions

What is a Text Diff Checker?

A Text Diff Checker compares two versions of content and highlights differences such as added, removed and unchanged lines.

Can I compare CSV data?

Yes. You can paste CSV data into both panels and compare the lines to identify changes between two versions.

Can I compare code?

Yes. You can compare HTML, CSS, JavaScript, SQL and other text-based code.

Is my data uploaded?

No server upload is required. The comparison is performed locally in your browser.

Can I download the comparison?

Yes. Use the Download Report button to save the generated difference report as a text file.
