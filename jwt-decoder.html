What is a JWT?

JWT stands for JSON Web Token. It is a compact format commonly used to transfer claims between systems. JWTs are frequently encountered in authentication and API applications.

JWT Structure

A typical JWT contains three Base64URL-encoded sections separated by periods:

  • Header — contains token metadata such as the algorithm.
  • Payload — contains claims and application data.
  • Signature — used to verify that the token was not altered.

Important Security Information

JWT decoding and JWT verification are different operations. Anyone who has a JWT can usually decode its header and payload. Therefore, decoded data should not automatically be considered trustworthy. Signature verification requires the appropriate cryptographic verification process and key.
