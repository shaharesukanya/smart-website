What is a Unix Timestamp?

A Unix timestamp represents a point in time as the number of seconds or milliseconds elapsed since the Unix epoch: January 1, 1970 at 00:00:00 UTC.

Seconds Example

1770000000

Milliseconds Example

1770000000000

Common Uses

  • API timestamps
  • Database records
  • JavaScript applications
  • Server logs
  • Data analysis
  • Event tracking

Timestamp Units

Seconds

Unix timestamps are commonly represented as whole seconds, for example:

1770000000

Milliseconds

JavaScript Date objects use milliseconds internally:

1770000000000

Frequently Asked Questions

What is an epoch timestamp?

It is a numeric representation of time measured from the Unix epoch, January 1, 1970 UTC.

What is the difference between seconds and milliseconds?

A millisecond is one thousandth of a second. Therefore a Unix timestamp in milliseconds is generally about 1,000 times larger than the equivalent timestamp in seconds.

Does the converter use my computer's timezone?

The local date result uses your browser's local timezone. The ISO and UTC results provide UTC-based representations.

Can I convert a date back to Unix time?

Yes. Select a date and time and choose seconds or milliseconds as the output unit.

Is my timestamp sent to a server?

No. The calculations happen directly in your browser.
