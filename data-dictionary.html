What is a Data Dictionary?

A data dictionary is a structured description of the columns in a dataset. It helps analysts and developers understand what each field contains and how the data can be used.

SmartTools automatically analyzes your CSV and creates a column-level overview including data type, missing values, unique values and numerical statistics.

What This Tool Analyzes

  • Column names
  • Detected data types
  • Total values
  • Missing values
  • Missing percentage
  • Unique values
  • Minimum value for numeric columns
  • Maximum value for numeric columns
  • Average for numeric columns

Frequently Asked Questions

What is a data dictionary used for?

A data dictionary helps users understand the structure, meaning and characteristics of fields in a dataset.

Which files are supported?

This tool is designed for CSV and compatible text-delimited files.

What data types are detected?

The tool can identify common text, numeric, date and boolean values based on the contents of each column.

Does the CSV get uploaded to a server?

No. The analysis happens locally in your browser.

Can I download the data dictionary?

Yes. Use the Download Report button to save the generated dictionary as a text report.
