How to Create a Strong Password

A few basic principles can make generated passwords more robust.

Use Sufficient Length

Longer passwords generally provide a larger number of possible character combinations than shorter passwords.

More length + more character variety = more possible combinations

Mix Character Types

Combining uppercase letters, lowercase letters, numbers and symbols increases the variety of characters used.

Avoid Easy-to-Guess Information

Avoid using obvious information such as names, birthdays, addresses or simple sequential patterns in passwords.

Use Unique Passwords

A password used for one account should not be reused across other important accounts.
