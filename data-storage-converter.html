Data Storage Conversion Basics

This converter uses binary-style multiples based on 1,024.

Bits and Bytes

A byte contains 8 bits.

1 Byte = 8 Bits

Kilobytes and Megabytes

In this calculator, each larger unit is based on 1,024 of the previous unit.

1 KB = 1,024 Bytes

Gigabytes and Terabytes

1 GB = 1,024 MB

1 TB = 1,024 GB

Petabytes

A petabyte is a very large digital storage unit often used when describing data-center, cloud or enterprise-scale storage.

1 PB = 1,024 TB

Common Conversion Examples

A few quick examples using the conversion system in this tool.

Bytes to Kilobytes

2,048 Bytes ÷ 1,024 = 2 KB

Megabytes to Gigabytes

1,024 MB ÷ 1,024 = 1 GB

Gigabytes to Terabytes

1,024 GB ÷ 1,024 = 1 TB

Bytes to Bits

10 Bytes × 8 = 80 Bits
